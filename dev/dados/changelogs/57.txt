(v 5.7)

It's been some time since I added more hexagons, mostly because adding them takes some more work due to scripting. Because of that I gathered all the hexagons I wanted to add in a single update, so our scripting wizard Saucekay won't kill me with my constant bothering. Anyway, every gym up to Gen 3 is now in the game - including the Kanto ones, which I was avoiding since the type specialist Trainer Cards are based on those Leaders, so I was not sure if I should add them or not. I did.

And talking about the type specialist Trainer Cards, those were tweaked too. I felt that they needed a little buff for some time, so they now get capturing bonuses (thanks reddit user PyreForMonitor - your feedback back on january is what put that on my mind.)

There was also a major reshuffle on the roster, check the full changelog below for all the changes. I'm thinking of adding all the Pokémon not currently in the roster as available to the game (Steam user painfulnoob has requested that recently, but it's been on my mind for some time), so I'll probably work on that next. Maybe adding each Generation with a mini-update.

Full changelog below. Got questions, any feedback or requests? Message me on Steam, tweet @dcandal or try r/pokemonmastertrainer on reddit. Thanks for playing.
