v6.1
Geral
  • The scripted setup has been improved, thanks to our colaborator smurfjames101. Now you can choose from 3 types of setups with a different roster of Pokémon:
    • Balanced Setup: the normal game, balanced between the different types.
    • Alternate Setup: here you will get a different roster of Pokémon, also balanced between different types. Think of it as the "Pokémon Red" to Balanced Mode's "Pokémon Blue".
    • Random Setup: with this one you will get a fully random roster of Pokémon in the game, not necessarily balanced for the types, but with their evolutionary families available.
  • Added support for Game Keys. Check [Options]->[Game Keys] to assign keys for Discarding, Rolling a Dice and Skiping your turn (also thanking smurfjames101 for that).

v5.7b

This minor update is focused on adding the Inactive Pokémon so players can add any of them to the game if they choose to do so. Now to the left of the main board you can see every Pokémon not in the active roster up to the 6th generation. Their 3D models are also added.

Keep in mind that the active roster is picked in order to make sure the different types are balanced, and the number of active Pokémon is meant to be reasonably balanced for 6 players.

Also, there are minor tweaks to the Stadium: there are now hidden slots for each player near the Stadium so preparation for battles is a little better. There are 6 slots for each color, placing your Pokémon there will keep them visible only to you. Then you can flip the cards and place them on the Stadium, so it's a little easier to prepare for battles.

Got questions, any feedback or requests? Message me on Steam, tweet @dcandal or try r/pokemonmastertrainer on reddit. Thanks for playing.

v5.7

It's been some time since I added more hexagons, mostly because adding them takes some more work due to scripting. Because of that I gathered all the hexagons I wanted to add in a single update, so our scripting wizard Saucekay won't kill me with my constant bothering. Anyway, every gym up to Gen 3 is now in the game - including the Kanto ones, which I was avoiding since the type specialist Trainer Cards are based on those Leaders, so I was not sure if I should add them or not. I did.

And talking about the type specialist Trainer Cards, those were tweaked too. I felt that they needed a little buff for some time, so they now get capturing bonuses (thanks reddit user PyreForMonitor - your feedback back on january is what put that on my mind.)

There was also a major reshuffle on the roster, check the full changelog below for all the changes. I'm thinking of adding all the Pokémon not currently in the roster as available to the game (Steam user painfulnoob has requested that recently, but it's been on my mind for some time), so I'll probably work on that next. Maybe adding each Generation with a mini-update.

Full changelog below. Got questions, any feedback or requests? Message me on Steam, tweet @dcandal or try r/pokemonmastertrainer on reddit. Thanks for playing.
