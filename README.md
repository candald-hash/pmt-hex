# Pokémon Master Trainer: HEX Edition — versão web

Jogo de tabuleiro de Douglas Candal, adaptado para o navegador.

- **Jogar:** abra o site publicado pelo GitHub Pages (a raiz deste repositório é o jogo: `index.html`, `css/`, `js/`, `img/`).
- **Desenvolvimento:** `dev/` tem o catálogo das cartas (`dados/`), o mapeamento dos hexágonos (`hex-mapa.json`, `mapeador.html`) e os scripts que geram `js/data.js` (`tools/`).
- Regras automatizadas e novidades: veja `LEIAME.md`.
